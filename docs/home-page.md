# Главная страница

## Назначение

Главная страница ориентирована на клиентов и представляет умный холодильник как основной
сценарий Shop With Me: учёт продуктов дома, выбор рецептов и составление списка недостающих
покупок в Telegram.

Информация о рабочем пространстве специалиста размещается только на странице
`/specialists`. На главной остаётся один переход на эту страницу в заключительном блоке.

## Компоновка

1. **Первый экран** — общий клиентский вход «Еда — в балансе. Покупки — по делу.»: сервис
   помогает вести записи, учитывать запасы и собирать покупки в Telegram. Основное действие —
   открыть бота; ссылка «Как устроен бот» ведёт к разделу с шагами работы.
2. **Возможности для клиентов** — рецепты из имеющихся продуктов, покупки без дублей,
   пополнение запасов текстом и голосом, просмотр и редактирование содержимого холодильника.
3. **Как это работает** — четыре шага: сообщить о покупках, выбрать блюдо, получить список
   недостающего, обновлять запасы.
4. **Пример диалога** — запрос списка покупок для конкретного блюда с учётом домашних запасов.
5. **Вопросы и ответы** — ввод продуктов, выбор рецепта, пустой холодильник и списание
   остатков.
6. **Переход для специалистов** — ссылка на `/specialists` в самом конце основного содержимого.

## Навигация

- В шапке главной нет ссылки «Специалистам». Навигация ведёт к разделам главной; ссылка на
  клиентскую страницу `/nutrition` может сохраняться.
- В подвале главной нет ссылки «Специалистам».
- Основная кнопка в шапке и на первом экране открывает Telegram-бота.
- Страница `/specialists` и её содержимое остаются самостоятельными.

## Оформление и метаданные

- Используются существующие компоненты, классы, цвета, типографика и карточки сайта. Новый
  визуальный стиль не вводится.
- Заголовок и описание главной для поисковых систем описывают умный холодильник, рецепты и
  список покупок.
- Отдельные страницы `/fridge`, `/nutrition` и `/specialists` сохраняются.
