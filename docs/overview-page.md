# Страница обзора направлений

## Замысел

`/overview` сохраняет изначальную главную страницу Shop With Me из коммита `19280dc` — общий
вход для трёх сценариев: питание со специалистом, рабочее пространство специалиста и умный
холодильник. Страница нужна как альтернативная презентация сервиса и не заменяет текущую
клиентскую главную `/`.

## Доступ

- Страница открывается только по прямому адресу `/overview`.
- Ссылок на `/overview` нет в шапках, подвалах, основном содержимом и других элементах
  навигации сайта.
- Изначальные ссылки внутри самой страницы на `/nutrition`, `/specialists` и `/fridge`
  сохраняются.

## Содержимое и оформление

- Компоновка, тексты и оформление восстанавливаются из версии главной в коммите `19280dc`.
- Первый экран представляет сервис целиком, затем идут карточки трёх направлений, объяснение
  диалогового формата и заключительный переход к выбору сценария.
- Используются существующие компоненты и стили сайта; новый визуальный стиль не вводится.
- Страница статически пререндеривается без клиентского JavaScript, как остальные продуктовые
  страницы. Канонический адрес и Open Graph URL указывают на `/overview`.
